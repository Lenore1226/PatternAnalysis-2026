# TimeGAN for Limit Order Book Generation

COMP3710 Final Report — Project 7 (Hard Difficulty)

This project investigates synthetic financial limit order book
generation using TimeGAN and the LOBSTER AMZN Level-10 dataset.

The research focuses on temporal fidelity, market microstructure
constraints, baseline comparisons, and computational efficiency.

## Project Status

Initial data validation and small-scale GPU feasibility testing
have been completed on UQ Rangpur.
